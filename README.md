# Icebreaker Game 🎯

A two-player question game built with React 19 + Vite. Players take turns answering randomised questions from themed categories, then rate each other's responses.

**Live:** https://jessisena.github.io/icebraker-game/

## Categories

Nine themed categories including personal questions, philosophical dilemmas, creative challenges, music trivia, and more — spanning over 245 questions and 180 songs.

## Tech stack

- React 19 · Vite 6
- CSS Modules + CSS custom properties (design-token driven)
- No backend — all state in `localStorage`
- i18next (Spanish UI, English questions)

## Local development

```bash
npm install
npm run dev        # Start dev server
npm run lint       # ESLint (zero warnings)
npm run test       # Vitest
npm run build      # Production build
npm run preview    # Preview production build
npm run format     # Prettier
```
